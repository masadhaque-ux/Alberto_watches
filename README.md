# Mederian

Mederian is the React JSX version of the Maison Horlogerie source project. It keeps the original page sections, visual styling, watch collection interactions, GSAP scroll effects, motion animations, gallery, and contact form.

## Requirements
- Node.js 20.19+ or 22.12+ (recommended for Vite 8)
- npm

## Run locally
1. Extract the ZIP.
2. Open a terminal in the `Mederian` folder.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed by Vite.

`node_modules` is intentionally not included. `package.json` lists the required dependencies.
